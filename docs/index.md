# IBDmix Documentation

Welcome to the IBDmix documentation! IBDmix is a tool for identifying introgressed segments in modern human genomes.

## Overview

IBDmix identifies segments of archaic ancestry in modern human genomes by comparing patterns of linkage disequilibrium and allele frequencies between modern and archaic populations.
